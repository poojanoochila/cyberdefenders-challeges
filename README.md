# CyberDefenders Labs

## Overview

This repository contains my hands-on investigations and walkthroughs of security challenges completed on the CyberDefenders platform.

The purpose of this repository is to document my practical cybersecurity learning journey and demonstrate skills relevant to Security Operations Center (SOC) Analyst, Threat Hunter, and Incident Response roles.

Each lab includes investigation notes, findings, Indicators of Compromise (IOCs), attack analysis, and lessons learned.
