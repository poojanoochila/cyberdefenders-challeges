# 📖 About This Repository

This repository contains my solutions and investigation reports for **CyberDefenders Blue Team challenges**.

Unlike traditional walkthroughs, these write-ups **do not publish challenge answers or flags**. Instead, they document:

* My investigation methodology
* The forensic artifacts I analysed
* Why specific evidence was important
* Tools and techniques used
* Skills gained during each investigation
* Lessons learned applicable to real-world Security Operations Centers (SOC)

The objective is to build a professional portfolio that reflects how a SOC Analyst approaches security investigations rather than simply solving Capture The Flag (CTF) challenges.

# 🔍 Investigation Methodology

Every investigation follows a structured workflow similar to real-world incident response.

```text
Evidence Collection
        │
        ▼
Artifact Identification
        │
        ▼
Evidence Analysis
        │
        ▼
Event Correlation
        │
        ▼
Timeline Reconstruction
        │
        ▼
MITRE ATT&CK Mapping
        │
        ▼
Lessons Learned
```

Rather than searching directly for challenge answers, I focus on understanding **how the attack happened**, **what evidence supports each finding**, and **how the investigation can be reproduced**.
