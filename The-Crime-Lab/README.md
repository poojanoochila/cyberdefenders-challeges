This repository documents my investigation process while completing **The Crime Lab** challenge on CyberDefenders.

Rather than publishing challenge answers, this write-up focuses on **how I analysed an Android device**, **which forensic artifacts helped reconstruct the victim's activities**, and **what I learned** throughout the investigation. # Scenario

As part of a homicide investigation, investigators recovered the victim's Android phone as a primary source of digital evidence.

My objective was to analyse the extracted Android data to reconstruct the victim's recent activities, identify significant contacts, examine communications, investigate travel information, and establish a timeline of events leading up to the incident.

# Investigation Walkthrough

---

## Objective 1 – Investigate Installed Applications

### My Approach

I began by reviewing the installed applications extracted by ALEAPP to understand the victim's interests and identify applications relevant to the investigation.

Rather than focusing only on application names, I inspected application metadata, installation details, and digital signatures that could support evidence validation.

### Why I Looked There

Installed applications often provide valuable insight into user behaviour, financial activity, and applications relevant to the investigation.

### Skills Practiced

* Android Application Analysis
* Mobile Artifact Analysis
* Hash Verification

### What I Learned

Application metadata can reveal valuable forensic information beyond simply identifying installed software.

---

## Objective 2 – Analyse Communications

### My Approach

Next, I investigated the victim's communication history by examining messages alongside call records.

Instead of analysing each artifact independently, I correlated missed calls with SMS conversations to understand the relationship between communication events.

### Why I Looked There

Correlating multiple communication sources provides stronger investigative evidence than analysing messages or call logs separately.

### Skills Practiced

* SMS Analysis
* Call Log Investigation
* Evidence Correlation

### What I Learned

Relationships between different communication artifacts often reveal important investigative context.

---

## Objective 3 – Identify Associated Contacts

### My Approach

After identifying relevant communications, I pivoted to the Contacts database to associate phone numbers with known individuals.

Rather than relying solely on phone numbers, I used contact information to provide meaningful context to communication records.

### Why I Looked There

Contacts transform anonymous phone numbers into identifiable individuals, making communication analysis significantly more valuable.

### Skills Practiced

* Contact Analysis
* SQLite Artifact Investigation
* Evidence Correlation

### What I Learned

Combining communication records with contact information strengthens attribution during forensic investigations.

## Objective 4 – Reconstruct User Location

### My Approach

To understand the victim's movements, I examined location-related artifacts generated by installed applications.

# Defensive Recommendations

* Enable full-device encryption on mobile devices.
* Regularly back up important data to preserve evidence if devices are lost.
* Protect sensitive applications using biometric authentication.
* Monitor application permissions to reduce unnecessary data exposure.
* Enable screen locks and strong authentication mechanisms.
* Preserve original mobile evidence before beginning forensic analysis.
* Validate findings by correlating multiple forensic artifacts.

---

# Key Takeaways

* Mobile devices contain evidence distributed across numerous applications rather than a single source.
* Correlating multiple artifacts produces stronger forensic conclusions.
* Timeline reconstruction is fundamental to mobile forensic investigations.
* Application metadata provides valuable evidence beyond user-generated content.
* Structured forensic methodology improves investigation accuracy and documentation quality.

# Reflection

This challenge strengthened my understanding of Android endpoint forensics by demonstrating how mobile artifacts can be used to reconstruct real-world events during a criminal investigation.

Instead of searching directly for answers, I learned how to analyse application data, communication records, contact information, travel artifacts, and messaging applications to build a coherent investigative timeline.

The investigation improved my confidence in using ALEAPP to analyse Android extractions, examining SQLite databases, correlating digital evidence across multiple artifacts, and documenting findings using a structured forensic methodology.

The biggest lesson from this lab was that valuable evidence is rarely found in a single artifact. Successful mobile forensic investigations require correlating information from multiple applications to reconstruct user activity accurately.
